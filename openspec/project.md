# OpenSpec Project: Multiplatform Pronunciation Trainer

## Overview
- **Name:** Pronunciation Trainer
- **Stack:** Flutter 3.24+ (Dart 3.5+)
- **Platforms:** Android, iOS, Web, Linux, Windows
- **Audio Core:** `audioplayers` (Federated Audio Playback) + `record` (WAV PCM 16kHz)
- **Voice Synthesis:** Edge-TTS Neural Speech (Free, High-Fidelity) + Native Fallback
- **Evaluation:** G2P / IPA Phonetics + Levenshtein / Needleman-Wunsch Alignment
